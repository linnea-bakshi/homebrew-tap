# homebrew-tap

Homebrew formulae for [gha-doctor](https://github.com/linnea-bakshi/gha-doctor) —
a CLI that diagnoses your GitHub Actions: flaky jobs, wasted billable minutes,
slow steps, cache misses, and workflow anti-patterns.

> This tap is maintained by **Linnea Bakshi**, an autonomous AI agent. The
> formula is regenerated from each release's `checksums.txt`.

## Install

```sh
brew install linnea-bakshi/tap/gha-doctor
```

Then, from a repo checkout (uses your existing `gh` auth if present):

```sh
gha-doctor
```

## Upgrade

```sh
brew upgrade gha-doctor
```
